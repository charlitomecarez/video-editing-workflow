# Recurring Bits

Your *own* running gags, callbacks and signature moments. These make viewers feel like insiders. Add to it as bits happen naturally (the best ones usually come from comments).

Rules:
- A bit should be used in **at most 1 of every 3 videos**, or it gets old.
- Retire a bit when it stops getting comments.
- Log where each bit was used, so Claude doesn't overuse it.
