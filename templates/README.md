# Templates

Save reusable Kdenlive starting points here, e.g. `tech-explainer.kdenlive` with the dark background, tracks (V1 background, V2/V3 visuals, A1 voice, A2 music, A3 SFX), your saved "Pop In" effect and title styles.

Start a video from one by copying it into the project folder and renaming it.
Note: media files referenced by a template (logos, backgrounds) should live in `templates/assets/`. Those are git-ignored like all media, so back them up.
