# References

Put reference videos you want to study here (for private study only. Don't reupload other creators' work). Video files are git-ignored. The analysis reports (`*_cuts/report.md`) and your notes are committed.

```bash
python3 tools/analyze_cuts.py references/<video>.mp4 --frames
```
Or run `/analyze references/<video>.mp4` in Claude Code.

Keep a note per reference in `notes.md`: what you like about it, what to steal (the technique, not the content).
